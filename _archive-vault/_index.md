# Archive Vault

Retired and archived content. Items moved here are no longer active.

## What lives here
- Completed projects (archived after shipping)
- Deprecated plans and specs
- Old versions superseded by newer docs

## What doesn't live here
- Active project work (use `projects/`)
- Current ops docs (use `ops/`)
- Anything referenced by an active project

## Navigation
Check `_index.md` before searching this folder manually.
