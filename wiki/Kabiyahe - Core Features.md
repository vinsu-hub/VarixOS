# Kabiyahe — Core Features

Part of [[Kabiyahe - Overview]].

## User Features

- **Browse & Search** — search destinations, filter by region/type/verified
- **Filters** — Region, Type, Open now, Verified, Dining (badge: Dine), Coffee (badge: Coffee)
- **Community badges** — Dine, Coffee, Gotcha, Custom, Add Badge
- **View location** — detail modal (map, hours, link, verified status)
- **Save to Trip** — Trip Selector overlay with Create + Edit Flow
- **Trip Builder** — pre-made itineraries and DIY custom plans

## Trip Builder

- Start from pre-made itinerary or DIY
- Add stops (draggable, orderable)
- Toggle travel time on/off
- Smart Day Planner (AI-based or template-based)
- Notes per stop
- Save/Share trips

## Travel Time

- **DRIVING** (moto/taxi)
- **CYCLING**
- **WALKING**
- **OPTIMAL** (best route, traffic-normalized)
- Uses Mapbox Directions API

## Social Layer

- **Comments / Reply** — “who actually lives there”
- **Post a snap / Upload photo** — with SBH counter
- **Someone Been Here (SBH)** — social proof on every pin, seen by others
- **SBH counter** — unauthenticated count on map pins

## Saved Trips

- Saved trips list → edit/delete
- Saved trip detail → reordered stops, back on map
