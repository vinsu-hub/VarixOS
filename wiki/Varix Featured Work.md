# Varix Featured Work

Portfolio showcase for [[Varix - Overview]]. Shipped and in-progress projects demonstrating core capabilities.

## Shipped

### Farmsy — Local Farm Discovery Platform
**Location:** Netherlands & Belgium
**Stack:** Full-stack web + native iOS + Android
**Status:** Live on Google Play, iOS in progress

Full end-to-end product build connecting users with 8,000+ verified farms — farm shops, organic producers, pick-your-own locations. Map-based discovery, SKAL-certified organic listings, direct farm contact. Stripe subscription model (yearly and lifetime tiers).

**Demonstrates:** Full-stack architecture, cross-platform mobile, geolocation/map-based design, Stripe integration, production deployment at real user scale.

### Summit Sports Academy — Youth Athlete Development
**Location:** Los Baños, Laguna
**Stack:** Web platform
**Status:** Live (`summit-sports-academy.vercel.app`)

Web platform for a youth athlete development nonprofit — program information, athlete engagement, organizational visibility.

### Istoria Coffee — Café Marketing Site & Community Wall
**Location:** Bay, Laguna
**Stack:** Vite + React 19 + Supabase
**Status:** Live (`istoria-vince-tamis.vercel.app`)

Menu, ordering info, and "Freedom Wall" community guestbook with server-side content moderation. Taglish on Freedom Wall, English elsewhere.
