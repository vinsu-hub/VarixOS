# Daily Notes

Daily work logs and observations.

## What lives here
- One file per date
- Quick notes, blockers, wins
- Links to relevant project files

## What doesn't live here
- Structured project plans (use `projects/`)
- Finished deliverables (use `content/`)
- Recurring ops docs (use `ops/`)
